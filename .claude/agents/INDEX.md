# Agent Index

- `component-builder`: Build frontend components, hooks, or pages with glassmorphism and wagmi/Zustand patterns.
- `deployer`: Deploy contracts and AVS/WAVS services; run codegen and env sync after contract changes.
- `frontend-design-validator`: Validate frontend TypeScript, React patterns, web3 integration, and glassmorphism design consistency.
- `investigator`: Debug errors, test failures, and unexpected behavior; identify root causes.
- `rust-wasi-dev`: Work on Rust/WASI components, WIT, and WASM builds in `packages/`.
- `solidity-reviewer`: Review Solidity changes for security, gas, and best practices.
- `test-runner`: Run tests across contracts and frontend; fix failing tests.
